# Papaya HatidGo: Download and User Manual

The download page and user manual for the **Papaya HatidGo** tricycle ride-hailing app (a BSIT project).

- **Website:** https://dosss42.github.io/papaya-hatidgo-manual/
- **The app (APK):** the newest file on this repo's [Releases](https://github.com/Dosss42/papaya-hatidgo-manual/releases/latest)

This repo holds only the website: `index.html` and the screenshots in `img/`. The app's source code is in its own repositories.
